# Как запустить лабораторную в Replit — вариант 6 «Кинотеатр»

## Что в архиве

```
.replit                 — команда запуска для кнопки Run (лежит в КОРНЕ, это важно)
Лабораторная 1/         — сам Django-проект
КАК-ЗАПУСТИТЬ.md        — этот файл
```

`.replit` должен остаться в корне рабочей папки Repl, а не внутри «Лабораторная 1» — Replit читает его только из корня.

## Шаг 1. Положить файлы в свой репозиторий на GitHub

Через сайт GitHub: открыть репозиторий → **Add file → Upload files** → перетащить распакованную папку целиком → **Commit changes**.

## Шаг 2. Импортировать репозиторий в Replit

1. На replit.com слева **Import** → вкладка **GitHub** → **Connect GitHub account** (если репозиторий приватный, без подключения он не появится в списке).
2. Выбрать свой репозиторий → **Import**.

Альтернатива без GitHub: **New** → App → шаблон **Python**, затем перетащить файлы из архива прямо в файловое дерево Replit.

## Шаг 3. Установить зависимости и подготовить базу

Открыть **Shell** (вкладка **+** на панели вкладок → `Shell`) и выполнить одной командой:

```bash
cd "Лабораторная 1" && pip install -r requirements.txt && python manage.py migrate && python manage.py loaddata movies
```

Затем создать администратора (интерактивный ввод пароля в Replit работает нестабильно, поэтому через переменные окружения):

```bash
DJANGO_SUPERUSER_USERNAME=admin DJANGO_SUPERUSER_PASSWORD=admin12345 DJANGO_SUPERUSER_EMAIL=admin@example.com python manage.py createsuperuser --noinput
```

## Шаг 4. Запустить

Нажать зелёную кнопку **Run** и открыть вкладку **Preview**.

Кнопка Run работает только если `.replit` лежит в корне. Проверить: `ls -a` в корне (`cd ~/workspace`) должен показать `.replit`.

Что смотреть:

| Адрес | Что там |
|---|---|
| `/` | «Hello, Django!» |
| `/movies/` | афиша из 8 фильмов + поиск |
| `/movies/1/` | карточка фильма |
| `/movies/add/` | форма добавления (доп. задание) |
| `/admin/` | админ-панель, логин `admin`, пароль `admin12345` |

## Шаг 5. Оформить отчёт

1. Снять 4 скриншота (список — в `Лабораторная 1/screenshots/README.md`), положить их в папку `screenshots/`.
2. В `Лабораторная 1/ОТЧЁТ.md` заполнить ФИО, группу, номер работы и ссылку на Repl.

## Если что-то пошло не так

**`That port is already in use`** — сервер уже запущен. Остановить и запустить заново:

```bash
pkill -f "manage.py runserver"
```

**Preview пишет «Your app is not running»** — Preview показывает только процесс, запущенный кнопкой **Run**, а не команду из Shell. Остановить ручной сервер (Ctrl+C) и нажать Run.

**`DisallowedHost` или `CSRF verification failed`** — не должно возникнуть: `ALLOWED_HOSTS = ['*']` и `CSRF_TRUSTED_ORIGINS` для доменов Replit уже прописаны в `mysite/settings.py`.

**Файлы правились в Replit и их надо вернуть на GitHub:**

```bash
cd ~/workspace && git add -A && git commit -m "Лабораторная 1" && git push
```
